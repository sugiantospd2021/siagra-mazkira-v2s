📖 Cara Pakai Backup

💾 Cara Backup (Simpan):
1. Klik tombol "Download Backup (JSON)" di atas
2. File akan otomatis tersimpan di folder Downloads
3. Pindahkan file ke Google Drive / Flashdisk sebagai cadangan
4. Lakukan minimal 1x seminggu
📥 Cara Restore (Kembalikan Data):
1. Klik tombol "Restore dari Backup" di atas
2. Pilih file .json yang pernah Anda download
3. Akan muncul konfirmasi — klik OK
⚠️ Peringatan Penting:
• Backup menyimpan data di browser ini (localStorage)
• Kalau ganti komputer/HP, file backup tetap bisa dipakai
• Simpan di minimal 2 tempat berbeda
